Aim:
     To develop a Python-based electricity billing system that calculates energy consumption charges using
    slab rates, conditional statements, and loops.
    
Algorithm:
          1. Start the program.
          2. Read the number of customers.
          3. For each customer, read the customer’s name and electricity units consumed.
          4. Determine the applicable slab rates based on the units consumed.
          5. Calculate the bill amount slab by slab.
          6. Display the units and calculated bill amount.
          7. Repeat for all customers and stop.

Result:
        Thus, the electricity billing system using conditional statements, loops, and slab-based calculations
        was implemented and executed successfully.
